📊 扩散模型的两个过程

1️⃣ 前向扩散过程（Forward Diffusion）

逐步向数据添加噪声，直到变成纯随机噪声。

x₀ → x₁ → x₂ → ... → xₙ → ... → x_N

数学表示：

# 每一步添加一点噪声
xₙ = √(αₙ) · xₙ₋₁ + √(1 - αₙ) · ε

其中：
- αₙ：控制保留多少原始信息
- ε：随机噪声（通常从正态分布采样）
- n：当前步数（从 1 到 N）

2️⃣ 反向去噪过程（Reverse Diffusion）

从纯噪声开始，逐步去除噪声，恢复出原始数据。

x_N → x_{N-1} → ... → xₙ → xₙ₋₁ → ... → x₀

数学表示：

# 神经网络预测噪声
ε_θ(xₙ, n) = 神经网络预测的噪声

# 去除噪声恢复前一步
xₙ₋₁ = (xₙ - √(1 - αₙ) · ε_θ(xₙ, n)) / √(αₙ)

🧠 训练目标

训练神经网络预测每一步添加的噪声：

# 给定加噪后的数据 xₙ 和步数 n
# 神经网络要学会预测原始噪声 ε

loss = MSE(ε_θ(xₙ, n), ε)

其中：
- ε：真实添加的噪声
- ε_θ(xₙ, n)：神经网络预测的噪声
- MSE：均方误差

关键点：同一个神经网络，在所有时间步 n 都能工作！

🎯 Alpha 和 Beta 的关系

在代码中（model.py 第 80-88 行）：

# 第 81-84 行：计算 beta schedule
beta = betas_for_alpha_bar(
    steps,
    lambda n: math.cos((n + 0.008) / 1.008 * math.pi / 2) ** 2,
)

# 第 87-88 行：计算 alpha
alpha = 1 - beta
alpha_cumprod = torch.cumprod(alpha, dim=0)

参数含义：

  • beta：每步添加的噪声量（越大，噪声越多）
  • alpha = 1 - beta：保留的原始信息比例
  • alpha_cumprod：累积的 alpha，表示从 x₀ 到 xₙ 总共保留了多少信息
alpha_cumprod[n] = α₁ · α₂ · ... · αₙ

💡 类比理解

类比 1：墨水在水中扩散

  • 前向过程：一滴墨水在水中逐渐扩散，最终均匀分布
  • 反向过程：让扩散的墨水重新聚集回一滴

类比 2：修复损坏的画作

  • 前向过程：画作逐渐被污损，直到无法辨认
  • 反向过程：修复师逐步清除污渍，恢复原作

类比 3：语音降噪

  • 前向过程：清晰语音逐渐被背景噪声淹没
  • 反向过程：降噪算法逐步去除噪声，恢复清晰语音

📝 Marionette 中的扩散模型

Marionette 使用的是 Add-Thin 扩散模型，专门用于时间点过程：

  • 数据：事件序列（如用户签到时间戳）
  • 前向过程：逐步添加（Add）噪声事件
  • 反向过程：逐步删除（Thin）噪声事件

核心思想：通过添加和删除事件，学习生成真实的时间点序列！
