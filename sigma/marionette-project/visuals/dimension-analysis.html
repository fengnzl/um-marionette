📋 关键配置信息

# 从 configs.py 和 model.py 中：
emb_dim = temporal_hidden_dims  # 假设是 32
hidden_dims = temporal_hidden_dims  # 也是 32
emb_dim == hidden_dims  # 它们相等！

🔧 各个 Embedding 的生成过程

1️⃣ dif_time_emb (扩散时间嵌入)

# model.py 第 204-210 行
position_emb = NyquistFrequencyEmbedding(dim=emb_dim, timesteps=steps)
self.diffusion_time_encoder = nn.Sequential(
    position_emb,              # 输出: [batch, emb_dim]
    nn.Linear(emb_dim, emb_dim),   # 还是 [batch, emb_dim]
    nn.GELU(),
    nn.Linear(emb_dim, emb_dim),   # 还是 [batch, emb_dim]
)

# 所以 dif_time_emb 的维度是: [batch, emb_dim]
# 也就是: [batch, hidden_dims]

2️⃣ time_emb (事件间时间嵌入)

# model.py 第 199-202 行
position_emb = NyquistFrequencyEmbedting(
    dim=emb_dim // 2,  # 注意这里是 emb_dim 的一半！
    timesteps=max_time
)
self.time_encoder = nn.Sequential(position_emb)

# 使用时 (model.py 第 255-257 行):
time_emb = self.time_encoder(
    torch.cat([x_n.time, x_n.tau], dim=-1)  # 拼接了两个时间特征
).reshape(B, L, -1)

# 所以 time_emb 的维度是: [batch, sequence, emb_dim]
# 也就是: [batch, sequence, hidden_dims]

3️⃣ event_emb (事件序列嵌入)

# model.py 第 260 行
event_emb = self.sequence_encoder(time_emb)  # sequence_encoder 输出 emb_dims

# 所以 event_emb 的维度是: [batch, sequence, emb_dims]
# 也就是: [batch, sequence, hidden_dims]

4️⃣ cond_emb (条件嵌入)

# model.py 第 158 行
self.event_condition_encoder = nn.Embedding(200, self.cond_emb_size)
# 其中 cond_emb_size = hidden_dims (第 156 行)

# model.py 第 271 行
event_level_cond_emb = torch.cat([
    condition1_cond_emb,  # 每个: [batch, sequence, hidden_dims]
    condition2_cond_emb,
    condition3_cond_emb,
    condition4_cond_emb,
    condition5_cond_emb,
    condition6_cond_emb,
], dim=-1)

# 所以 cond_emb 的维度是: [batch, sequence, 6 * hidden_dims]

🎯 在 PointClassifier.forward 中的拼接

# classifier.py 第 58 行的 unsqueeze 和 repeat
x = torch.cat([
    time_emb,                              # [batch, seq, hidden_dims]
    event_emb,                             # [batch, seq, hidden_dims]
    dif_time_emb.unsqueeze(1).repeat(1, L, 1),  # [batch, 1, hidden_dims] → [batch, seq, hidden_dims]
    cond_emb,                              # [batch, seq, 6*hidden_dims]
], dim=-1)

# 总维度 = hidden_dims + hidden_dims + hidden_dims + 6*hidden_dims
#         = 9 * hidden_dims ✅

✅ 总结：为什么是 9 * hidden_dims？

Embedding 维度 倍数
time_emb [batch, seq, hidden_dims] 1×
event_emb [batch, seq, hidden_dims] 1×
dif_time_emb (广播后) [batch, seq, hidden_dims] 1×
cond_emb (6个条件) [batch, seq, 6*hidden_dims] 6×
总计 [batch, seq, 9*hidden_dims] 9×

关键发现：注释 "# 3 * hidden_dims" 实际上是不准确的！真正的计算是 1 + 1 + 1 + 6 = 9，而不是 3。
