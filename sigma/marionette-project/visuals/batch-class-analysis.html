📦 Batch 类的作用

Batch 类是一个智能容器，用于存储和处理一批序列数据。它不只是简单地把数据放在一起，还提供了很多方便的方法。

🎭 Batch 类中的魔术方法

1️⃣ __len__ (第 227-228 行)

@property
def batch_size(self) -> int:
    return self.time.shape[0]

def __len__(self):
    return self.batch_size

作用: 让 len(batch) 返回 batch_size

batch = Batch(...)
len(batch)  # 返回 32（如果 batch_size=32）

2️⃣ __getitem__ (第 230-231 行)

def __getitem__(self, key: str):
    return getattr(self, key, None)

作用: 让 Batch 像字典一样访问属性

batch = Batch(...)
batch['time']      # 等价于 batch.time
batch['mask']      # 等价于 batch.mask
batch['tau']       # 等价于 batch.tau

3️⃣ __setitem__ (第 233-234 行)

def __setitem__(self, key: str, value):
    setattr(self, key, value)

作用: 让 Batch 像字典一样设置属性

batch = Batch(...)
batch['new_attr'] = some_value  # 等价于 batch.new_attr = some_value

4️⃣ __iter__ (第 241-244 行)

def __iter__(self):
    for key in sorted(self.keys()):
        yield key, self[key]

作用: 让 Batch 可以用 for 循环遍历

batch = Batch(...)
for key, value in batch:
    print(f"{key}: {value.shape}")
# 输出:
# condition1: torch.Size([32, 100])
# condition2: torch.Size([32, 100])
# ...

5️⃣ __contains__ (第 246-247 行)

def __contains__(self, key):
    return key in self.keys()

作用: 让 in 操作符可以工作

batch = Batch(...)
'time' in batch  # 返回 True
'unknown' in batch  # 返回 False

🔧 核心方法：from_sequence_list (第 256-362 行)

这是一个静态方法，也是一个 collate_fn！

@staticmethod
def from_sequence_list(sequences: List[Sequence]) -> "Batch":
    """
    Create batch from list of sequences.
    """

它做的事情：

  1. Padding（填充）: 将不同长度的序列填充到相同长度
  2. Mask（掩码）: 创建掩码标记真实数据和填充位置
  3. Stacking（堆叠）: 将多个序列堆叠成一个 batch

关键代码片段：

# 第 264-267 行：填充 time
time = pad(
    [sequence.time for sequence in sequences],
    length=tau.shape[-1]
)

# 第 321-324 行：创建 mask
mask = (
    torch.arange(0, tau.shape[-1], device=device)[None, :]
    < sequence_length[:, None]
)

# 第 339-361 行：创建 Batch 对象
batch = Batch(
    mask=mask,
    time=time,
    ...
)
return batch

📊 Batch 对象的结构

属性名 形状 含义
time [batch, sequence] 事件时间戳
tau [batch, sequence] 事件间时间间隔
mask [batch, sequence] 标记真实数据（1=真实，0=填充）
condition1-6 [batch, sequence] 6 种条件信息
unpadded_length [batch] 每个序列的真实长度

💡 为什么 Batch 需要这么多魔术方法？

这些魔术方法让 Batch 类既像对象，又像字典，使用起来非常灵活：

# 1. 像对象一样访问属性
batch.time

# 2. 像字典一样访问
batch['time']

# 3. 遍历所有属性
for key, value in batch:
    print(key, value.shape)

# 4. 检查属性是否存在
if 'mask' in batch:
    print("Has mask!")

# 5. 获取大小
len(batch)  # batch_size
