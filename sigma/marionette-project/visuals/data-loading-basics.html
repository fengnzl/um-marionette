🔄 PyTorch 数据加载基础

为什么需要数据加载？

深度学习需要处理大量数据。我们不能一次性把所有数据加载到内存中，而是需要：

  • 分批处理：每次只处理一小批数据 (batch)
  • 并行加载：在 GPU 训练的同时，CPU 准备下一批数据
  • 数据增强：在加载时对数据进行预处理
  • 打乱顺序：每个 epoch 随机打乱数据顺序

1️⃣ Dataset（数据集）

职责：访问单个数据样本

class MyDataset(torch.utils.data.Dataset):
    def __len__(self):
        return len(data)  # 数据集大小

    def __getitem__(self, idx):
        return data[idx]  # 返回第 idx 个样本

关键点：只负责读取一个样本，不负责批处理

2️⃣ DataLoader（数据加载器）

职责：将多个样本组合成批次

dataloader = DataLoader(
    dataset,
    batch_size=32,      # 每批 32 个样本
    shuffle=True,       # 每个 epoch 打乱顺序
    num_workers=4,      # 4 个进程并行加载
)

关键点：DataLoader 会自动调用 Dataset 的 __getitem__

3️⃣ collate_fn（整理函数）

职责：将多个样本整理成一个批次

def my_collate_fn(batch):
    # batch 是一个列表: [sample1, sample2, ...]
    # 将它们转换成一个 tensor
    return torch.stack(batch)

dataloader = DataLoader(
    dataset,
    batch_size=32,
    collate_fn=my_collate_fn,  # 自定义整理函数
)

关键点：当样本长度不一致时，需要自定义 collate_fn

4️⃣ Batch（批次）

职责：存储一批数据

# 一个典型的 batch:
batch = {
    'x': tensor([[...], [...], ...]),  # [batch_size, features]
    'y': tensor([0, 1, 0, ...]),       # [batch_size]
}

关键点：Batch 中所有样本的第一维都是 batch_size

完整的数据流

# 1. 创建 Dataset
dataset = MyDataset(data)  # 封装数据访问

# 2. 创建 DataLoader
dataloader = DataLoader(
    dataset,
    batch_size=32,
    shuffle=True,
)

# 3. 训练循环中使用
for batch in dataloader:
    # 每个 batch 自动包含 32 个样本
    x, y = batch['x'], batch['y']
    output = model(x)
    loss = criterion(output, y)
    loss.backward()
    optimizer.step()

变长序列的处理

在序列数据（如文本、时间序列）中，不同样本的长度往往不同：

❌ 问题：不能直接堆叠

# 样本 1: [1, 2, 3]       # 长度 3
# 样本 2: [4, 5, 6, 7, 8]  # 长度 5

# 直接 stack 会报错！
torch.stack([sample1, sample2])  # ❌ Error!

✅ 解决：Padding（填充）

# 填充到相同长度
# 样本 1: [1, 2, 3, 0, 0]    # 用 0 填充
# 样本 2: [4, 5, 6, 7, 8]   # 不需要填充

# 现在可以堆叠了
batch = torch.stack([padded_sample1, sample2])
# batch: [[1, 2, 3, 0, 0],
#         [4, 5, 6, 7, 8]]

🎭 Mask（掩码）

填充后需要记录哪些是真实数据，哪些是填充：

mask = [[1, 1, 1, 0, 0],   # 样本 1: 前 3 个是真实数据
        [1, 1, 1, 1, 1]]   # 样本 2: 全部是真实数据

# 使用时:
valid_data = data * mask  # 填充位置变成 0
