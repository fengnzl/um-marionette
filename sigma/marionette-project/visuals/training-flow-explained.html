第 3 步：反向传播和参数更新

# tasks.py 第 146-157 行
def training_step(self, batch, batch_idx):
    loss_temporal, loss_spatial, loss_all = self.step(batch, "train")

    opt1, opt2 = self.optimizers()

    # 更新 temporal 模型
    opt1.zero_grad()                    # 清空梯度
    self.manual_backward(loss_temporal)  # 计算梯度
    opt1.step()                         # 更新参数

    # 更新 spatial 模型
    opt2.zero_grad()                    # 清空梯度
    self.manual_backward(loss_spatial)  # 计算梯度
    opt2.step()                         # 更新参数

💡 损失函数详解

1. Classification Loss（分类损失）

# tasks.py 第 46-54 行
def classification_loss(self, x_n_int_x_0, x_n: Batch):
    """
    计算二元交叉熵损失
    """
    x_n_int_x_0 = x_n_int_x_0.flatten()[x_n.mask.flatten()]
    target = x_n.kept.flatten()[x_n.mask.flatten()]
    loss = self.classification_loss_func(x_n_int_x_0, target.float())
    loss = (loss).sum() / len(x_n)
    return loss

理解要点：

  • 神经网络预测每个事件是否属于原始数据
  • 使用 BCE（二元交叉熵）损失
  • 目标是让预测尽可能接近真实标签

2. Intensity Loss（强度损失）

# tasks.py 第 56-60 行
def intensity_loss(self, log_prob_x_0):
    """
    计算负对数似然
    """
    return -log_prob_x_0.mean()

理解要点：

  • 评估事件序列的似然概率
  • 目标是让模型生成高似然概率的事件
  • 负号是因为我们想最大化似然，但优化器是最小化

🎯 训练的关键点

为什么有两个优化器？

# tasks.py 第 122-125 行
def configure_optimizers(self):
    # temporal 模型的优化器（Add-Thin）
    optimizer1 = torch.optim.Adam(
        self.tpp_model.parameters(),
        lr=self.learning_rate1
    )

    # spatial 模型的优化器（离散扩散）
    optimizer2 = torch.optim.AdamW(
        self.discrete_diffusion.parameters(),
        lr=self.learning_rate2
    )

原因：

  • Marionette 有两个独立的模型
  • Temporal 模型：处理事件时间（Add-Thin）
  • Spatial 模型：处理事件类型（离散扩散）
  • 它们需要不同的学习率和优化策略
