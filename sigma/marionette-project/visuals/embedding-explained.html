🎯 Embedding 概念解释

什么是 Embedding？

Embedding 是将离散数据（如数字、单词、类别）映射到连续向量空间的技术。

离散值
5
→
[0.1, 0.5, -0.3, 0.8, ...]

这样做的目的是让神经网络能够更好地理解和处理这些数据。

PointClassifier 中的 4 种 Embedding

Embedding 名称 输入是什么 输出维度 代表的含义
dif_time_emb 扩散时间步 n（一个数字） 3 × hidden_dims 当前在扩散过程的哪一步
time_emb 事件间的时间间隔 2 × hidden_dims 事件之间的时间关系
event_emb 事件类型/标记 3 × hidden_dims 事件内容的语义信息
cond_emb 条件信息 1 × hidden_dims 额外的上下文条件

🔢 维度计算

input_dim = 9 × hidden_dims

= (3 + 2 + 3 + 1) × hidden_dims
= dif_time_emb + time_emb + event_emb + cond_emb

所以：4 个 embedding 拼接后的总维度是 9 × hidden_dims！

为什么需要 Embedding？

❌ 不用 Embedding 的问题

# 假设时间步是 0, 1, 2, ..., 99
# 如果直接用这些数字：
step_50 = 50
step_51 = 51

# 网络可能会学到错误的模式：
# "51 比 50 大 1" —— 这个关系在扩散中没有意义！

✅ 使用 Embedding 的好处

# 使用 NyquistFrequencyEmbedding：
step_50 = [0.1, -0.5, 0.8, 0.3, ...]   # 丰富的高维表示
step_51 = [0.2, -0.4, 0.7, 0.4, ...]   # 平滑的变化

# 网络可以学到：
# - 每个时间步都有独特的"身份"
# - 相邻时间步之间有平滑的过渡
# - 包含多尺度的频率信息（快变和慢变）

🎵 NyquistFrequencyEmbedding 的工作原理

它使用正弦和余弦函数来生成 embedding：

# 对于时间步 t：
embedding = [
    sin(f₁ × t),      cos(f₁ × t),      # 频率 f₁（慢变）
    sin(f₂ × t),      cos(f₂ × t),      # 频率 f₂（中速）
    sin(f₃ × t),      cos(f₃ × t),      # 频率 f₃（快变）
    ...
]

# 频率范围：从 1/8（慢）到 Nyquist/2φ（快）
# 这样可以捕获不同时间尺度的信息

类比：就像音乐！一首曲子同时包含低音（慢变）和高音（快变），合起来才是丰富的音乐。

📊 在 PointClassifier 中的数据流

# 输入：4 个独立的 embedding
dif_time_emb:  [batch, 3*hidden_dims]     # 例如：[32, 96]
time_emb:      [batch, seq, 2*hidden_dims] # 例如：[32, 100, 64]
event_emb:     [batch, seq, 3*hidden_dims] # 例如：[32, 100, 96]
cond_emb:      [batch, seq, 1*hidden_dims] # 例如：[32, 100, 32]

# 处理：拼接
x = torch.cat([...], dim=-1)

# 输出：合并后的特征
x: [batch, seq, 9*hidden_dims]  # 例如：[32, 100, 288]

# 然后通过 MLP 处理
logits = self.model(x)  # [32, 100, 1]
