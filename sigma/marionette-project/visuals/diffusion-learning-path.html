🎯 从基础概念到 Marionette 实现

📚 学习路径图

你已经掌握了基础概念，现在需要理解它们在 Marionette 项目中的具体应用。

通用扩散模型 → Add-Thin 扩散模型

  • 通用模型：处理图像（像素是连续的）
  • Add-Thin：处理事件序列（事件是离散的）

🔑 核心差异理解

差异 1：数据类型

# 通用扩散模型（如 DALL-E）
数据：图像像素（连续值，如 RGB: [0.73, 0.21, 0.56]）
操作：加高斯噪声

# Add-Thin 扩散模型
数据：事件序列（离散事件，如 [(t1, type1), (t2, type2), ...]）
操作：添加新事件 + 删除现有事件

差异 2：噪声形式

# 通用扩散模型
噪声：高斯噪声（连续的随机值）
公式：xₙ = √(αₙ) · xₙ₋₁ + √(1 - αₙ) · ε

# Add-Thin 扩散模型
噪声：新事件（在随机时间点添加新的事件）
公式：更复杂（涉及添加概率和保留概率）

📖 阅读 Marionette 代码的指南

1从 DiffusionModel 基类开始

位置：add_thin/diffusion/model.py 第 66-104 行

class DiffusionModel(nn.Module):
    def __init__(self, steps: int = 1000):
        # 计算 alpha 和 beta schedule
        beta = betas_for_alpha_bar(...)  # 第 81 行
        alpha = 1 - beta                  # 第 87 行
        alpha_cumprod = torch.cumprod(alpha, dim=0)  # 第 88 行

理解要点：

  • 这里实现了标准的扩散模型调度（schedule）
  • 使用余弦调度（cosine schedule）
  • 计算了 alpha、beta、alpha_cumprod 等关键参数

2理解 Add-Thin 的特有方法

关键方法：

  • noise()：前向过程，向序列添加事件
  • sample_posterior()：反向过程，从序列删除事件
  • sample_x_0()：从 xₙ 采样 x₀

3理解两个核心模型

Add-Thin 使用了两个神经网络：

# 1. Classifier Model（分类器）
classifier_model = PointClassifier(...)
# 作用：预测 x₀ 和 xₙ 的交集（哪些事件应该保留）

# 2. Intensity Model（强度模型）
intensity_model = MixtureIntensity(...)
# 作用：计算事件的似然概率（用于采样新事件）

关键理解：通用扩散模型只有一个神经网络预测噪声，而 Add-Thin 需要两个模型分别处理不同的任务。

💡 学习建议

建议 1：先理解流程，再深究细节

# 第一步：理解训练流程
1. 获取原始数据 x₀
2. 随机采样时间步 n
3. 添加噪声得到 xₙ
4. 神经网络预测
5. 计算损失并更新

# 第二步：理解采样流程
1. 从纯噪声 x_N 开始
2. 逐步应用反向过程
3. 最终得到 x₀

建议 2：关注数据流

追踪数据在代码中的流动：

x₀ (原始数据)
  ↓ noise()
xₙ (加噪数据)
  ↓ compute_emb()
embeddings (特征表示)
  ↓ classifier_model()
logits (预测结果)
  ↓ loss calculation
loss (训练信号)

建议 3：对比理解

将通用扩散模型和 Add-Thin 进行对比：

# 通用模型
图像 → 加高斯噪声 → 神经网络预测噪声 → 去除高斯噪声 → 图像

# Add-Thin
事件序列 → 添加新事件 → 神经网络预测交集 → 删除事件 → 事件序列
