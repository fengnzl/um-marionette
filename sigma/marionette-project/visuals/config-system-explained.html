⚙️ Hydra 配置系统详解

什么是 Hydra？

Hydra 是一个优雅的 Python 配置管理框架，由 Facebook 开发。它让你能够：

  • 📁 通过 YAML 文件管理配置
  • 🔧 组合多个配置文件（模块化）
  • 🚀 命令行覆盖配置
  • 🎯 自动类型转换和验证
  • 📊 生成配置覆盖和日志

📂 Marionette 项目的配置结构

config/ ├── train.yaml # 主配置文件 ├── data/ │ └── data_set.yaml # 数据配置 ├── task/ │ └── density.yaml # 任务配置 ├── model/ │ └── Marionette.yaml # 模型配置 └── hydra/ └── default.yaml # Hydra 配置

🔍 train.yaml（主配置文件）

defaults:
  - data: data_set      # 引用 data/data_set.yaml
  - task: density       # 引用 task/density.yaml
  - hydra: default      # 引用 hydra/default.yaml
  - _self_              # 当前文件的配置优先
  - model: Marionette   # 引用 model/Marionette.yaml

trainer:
  _target_: pytorch_lightning.Trainer
  accelerator: gpu
  devices: [0]
  max_epochs: 1000

seed: 135398
project: Marionette

关键点：defaults 列表定义了配置文件的组合顺序。

💻 代码中的使用

train.py 中的 Hydra 装饰器

@hydra.main(config_path="config", config_name="train", version_base=None)
def main(config: DictConfig):
    # config 是一个 DictConfig 对象
    # 可以像访问字典或对象一样访问配置

    print(config.batch_size)        # 512
    print(config.temporal_hidden_dims)  # 32
    print(config.data.name)          # Istanbul

关键点：@hydra.main 装饰器自动加载配置并传入 main 函数。

🎯 命令行覆盖配置

Hydra 允许你在命令行中覆盖任何配置值：

# 使用默认配置运行
python train.py

# 覆盖 batch_size
python train.py batch_size=256

# 覆盖多个配置
python train.py batch_size=128 temporal_hidden_dims=64

# 切换数据集（通过配置组）
python train.py data=another_dataset

# 组合使用
python train.py batch_size=64 data=data_set model=Marionette

📋 配置合并顺序

在 defaults 列表中，后面的配置会覆盖前面的：

顺序 配置文件 作用
1 data: data_set 加载数据配置
2 task: density 加载任务配置（可能覆盖 data 配置）
3 hydra: default 加载 Hydra 配置
4 _self_ 当前文件的配置优先
5 model: Marionette 加载模型配置（优先级最高）

✨ Hydra 的优势

1. 模块化配置

# 不同数据集可以使用相同的模型配置
config/
├── data/
│   ├── Istanbul.yaml
│   ├── Tokyo.yaml
│   └── NYC.yaml
├── model/
│   ├── Marionette.yaml
│   └── Baseline.yaml

# 轻松切换
python train.py data=Tokyo model=Baseline

2. 实验跟踪

Hydra 自动为每次运行创建输出目录，保存配置和日志：

outputs/
├── 2023-10-01/
│   ├── 12-30-45/
│   │   ├── .hydra/
│   │   │   ├── config.yaml    # 使用的配置
│   │   │   └── overrides.yaml  # 命令行覆盖
│   │   └── checkpoints/

3. 类型安全

# YAML 中自动类型转换
learning_rate: 0.001    # float
batch_size: 512         # int
use_gpu: true           # bool
layers: [64, 128, 256]  # List[int]
