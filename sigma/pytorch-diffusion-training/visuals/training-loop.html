五个关键步骤，让神经网络学习

1
前向传播
数据通过网络，得到预测结果
outputs = model(inputs) # 模型预测
2
计算损失
比较预测和真实值，得到误差
loss = criterion(outputs, targets) # 计算误差
3
反向传播
计算每个参数的梯度
loss.backward() # 计算梯度
4
更新参数
沿梯度方向更新权重
optimizer.step() # 更新参数
5
清空梯度
清除累积的梯度，为下一轮准备
optimizer.zero_grad() # 清空梯度
⚠️
顺序很重要！
zero_grad() 必须在下一轮开始前
否则梯度会累积，导致错误的更新

🔑 关键点

  • forward： 数据从输入到输出，得到预测
  • loss： 使用之前学过的MSE或交叉熵
  • backward： 自动求导，计算每个参数的梯度
  • step： 使用梯度下降（或其他优化器）更新参数
  • zero_grad： 默认情况下梯度会累积，必须手动清空

完整代码示例

for inputs, targets in dataloader: # 1. 前向传播 outputs = model(inputs) # 2. 计算损失 loss = criterion(outputs, targets) # 3. 反向传播 optimizer.zero_grad() # 清空上一轮的梯度 loss.backward() # 计算当前梯度 # 4. 更新参数 optimizer.step() # 沿梯度方向更新
